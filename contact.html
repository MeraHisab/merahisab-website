Frequently Asked Questions





How can I contact MeraHisab?



Use the available support information
on this page. Direct support email
and ticket submission are pending configuration.









Does generating a request submit a ticket?



No. The request builder creates a local
draft that you can copy or download.









Why is my APK not downloading?



Check your internet connection,
available storage and browser download settings.
Visit the APK Download page for guidance.









Why is the application not installing?



Possible causes include an incomplete
download, incompatible Android version,
insufficient storage or signing conflicts.
Do not bypass Android security warnings.









Can I recover deleted financial records?



Recovery depends on available backups
and the application's recovery features.
Avoid clearing storage or uninstalling
before securing existing records.









How do I report a bug?



Select Bug Report in the request builder.
Describe the problem and steps to reproduce it.
Do not include private financial information.









How can I suggest a new feature?



Select Feature Suggestion and prepare
a description of the proposed improvement.









Is Royal Khata available for download?



The official Royal Khata APK release
is pending. Visit its application page
for development information.









Can I report a security vulnerability?



Prepare a Security Report containing
a safe description of the issue.
Do not include credentials, recovery keys
or other sensitive records.
A verified reporting channel is pending.









Does this page save my support information?



The request builder does not intentionally
save form information to browser databases
or send it to a server. Browser behavior
and downloaded copies are managed separately.









Can I submit a privacy or deletion request?



You can prepare a Privacy Request locally.
Official request delivery and handling
procedures still require configuration.









How do I install the website as a PWA?



Open the homepage and use the available
website installation controls in a
supported browser.
