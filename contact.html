Protect Your Sensitive Information

Important Security Notice

Never include the following information in a support request:

  • Passwords
  • Application PINs
  • One-Time Passwords (OTPs)
  • Recovery keys
  • Encryption passwords
  • Bank account credentials
  • Debit or credit card details
  • Confidential financial records
  • Unredacted customer information

Remove sensitive information from screenshots and technical reports before sharing them.

Read Privacy & Security Information

Frequently Asked Questions


            


                Find answers to common
                questions about our applications
                and website.

            


            

            


                

                    What is MeraHisab?

                

                


                    MeraHisab is a personal
                    financial management application
                    designed to help users organize
                    their everyday financial records.

                


                

                    Learn more about MeraHisab

                

            


            

            


                

                    What is Royal Khata?

                

                


                    Royal Khata is a digital
                    ledger project focused on
                    credit-debit management
                    and customer account records.

                


                

                    Learn more about Royal Khata

                

            


            

            


                

                    Where can I download the applications?

                

                


                    Visit the official download
                    center to check available
                    application releases and
                    download information.

                


                

                    Official Download Center

                

            


            

            


                

                    Is Royal Khata available for download?

                

                


                    Royal Khata download availability
                    depends on its release status.

                    Check the official application
                    page for current information.

                


                

                    Check Royal Khata Information

                

            


            

            


                

                    How can I safely install an APK?

                

                


                    Download application files
                    only from trusted official
                    distribution channels.

                    Review Android installation
                    warnings and verify available
                    release information before
                    proceeding.

                


                


                    Do not disable Play Protect
                    or other device security
                    safeguards to install an APK.

                


            


            

            


                

                    How can I protect my financial data?

                

                


                    Use a secure device screen lock,
                    enable supported application
                    security features and maintain
                    verified financial backups.

                    Keep your passwords and
                    recovery information confidential.

                


                

                    Read Privacy & Security Information

                

            


            

            


                

                    What happens if I lose my recovery key?

                

                


                    Where a recovery key is required,
                    losing it may prevent access
                    to protected information.

                    Recovery possibilities depend
                    on the application version
                    and security implementation.

                


                


                    Never share your recovery key
                    with another person.

                


            


            

            


                

                    Will uninstalling the app delete my data?

                

                


                    Uninstalling an application
                    may remove locally stored
                    application information.

                    Separately stored backups
                    may remain available depending
                    on their storage location.

                


                


                    Always verify your backup
                    before uninstalling an app.

                


            


            

            


                

                    How can I request data deletion?

                

                


                    Use available application
                    data management features
                    to manage local records.

                    You can also prepare a
                    data deletion request using
                    the support request form.

                


                


                    Preparing a request does not
                    automatically submit or
                    complete a deletion request.

                


                

                    Prepare Data Deletion Request

                

            


            

            


                

                    Are website financial calculators free?

                

                


                    The financial calculators
                    provided on our website
                    are available without a
                    payment requirement.

                    Results are estimates and
                    should be independently verified.

                


                

                    Open Financial Tools

                

            


            

            


                

                    How can I report a security vulnerability?

                

                


                    Select Security Vulnerability
                    Report in the support form
                    and prepare a responsible
                    technical description.

                


                


                    Do not include real user data,
                    passwords, recovery keys or
                    confidential financial information.

                    Do not access or modify
                    information belonging to
                    other users.

                


                

                    Prepare Security Report

                

            


            

            


                

                    Does this contact form send messages?

                

                


                    No. The current form prepares
                    a support request locally
                    in your browser.

                    You can review, copy or
                    download the prepared request.

                    Direct message delivery requires
                    a configured support service.
