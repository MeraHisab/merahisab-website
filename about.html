Our Story

Managing everyday financial records can become difficult when information is scattered across notebooks, messages and multiple documents.

MeraHisab is being developed with the objective of making financial record management more organized, accessible and understandable.

The project brings together two application concepts: MeraHisab for personal financial management and Royal Khata for digital credit and debit records.

The official website also brings application information, financial calculators, download resources, privacy information and support guidance into one place.

Frequently Asked Questions

What is MeraHisab?

MeraHisab is a financial management project that includes a personal finance application and an official website with financial tools.

What is Royal Khata?

Royal Khata is a digital ledger application project focused on credit, debit and business financial records.

Are MeraHisab and Royal Khata the same application?

No. They are separate application projects with different financial management objectives.

What is the official website?

The official project website is https://merahisab.store/.

Is Royal Khata available for download?

Royal Khata's APK release is currently pending. Visit its application page for development information.

Can I install the website on my phone?

Supported browsers may allow installation of the website as a Progressive Web App. Availability depends on the browser, device and successful PWA setup.

Is website installation the same as APK installation?

No. A PWA installs the website experience, while an Android APK installs a separate native Android application.

Can the website work offline?

Selected public website resources may work offline after successful service worker installation and caching.

Where can I read about privacy?

Visit the Privacy & Data Protection page for privacy information, storage details and security guidance.

Does MeraHisab provide financial advice?

The website provides financial information, record management resources and calculation tools, not personalized financial advice.
