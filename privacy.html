7. PWA and Offline Storage

The MeraHisab website includes Progressive Web App functionality.

Its service worker is designed to cache selected public website pages, stylesheets, scripts and icons to support offline access.

  • Offline access depends on successful caching.
  • APK downloads are excluded from the intended PWA cache.
  • Contact and download pages are excluded from the intended page cache.
  • Website cache storage is separate from native Android application storage.
  • Clearing the website cache may remove offline resources.

Users can access available PWA storage controls through the installation and diagnostics panel on this website.

9. Backups and Data Recovery

Users should maintain independent backups of important financial records using available application features.

Privacy Frequently Asked Questions

Are my financial records uploaded to a server?

The website calculator engine processes inputs locally. Native application data flows require separate verification.

Does the website save calculator inputs?

The calculator engine does not intentionally persist entered amounts or calculation results. Browser behavior may vary according to browser settings.

Does the website use cookies?

Website preferences may use browser storage. Hosting or external services may have their own storage practices. A complete cookie audit is pending.

Are application records encrypted?

Encryption implementation must be verified separately for each released application before making this claim.

Can I clear website storage?

Yes. Use browser site settings or the available PWA storage controls. Clearing website cache may remove offline functionality until resources are downloaded again.

Will clearing website cache delete Android app records?

The website cache and native Android application storage are separate. Do not clear native application storage without securing a backup.

Can I request deletion of personal data?

Applicable privacy rights may include requesting erasure. The official request handling contact and procedures require configuration.

Does APK checksum verification guarantee safety?

No. A checksum comparison establishes file integrity against a valid reference. It does not independently establish malware safety or developer authenticity.

Can I use the website offline?

Selected public website resources may be available offline after successful PWA caching.

How can I report a privacy issue?

Visit the Contact & Support page for available reporting information. Do not include unnecessary sensitive financial information.
