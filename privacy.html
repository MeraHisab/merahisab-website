06. Backup & Recovery

Maintaining reliable backups is important for protecting personal and business financial records.

6.1 Backup Features

Depending on the application and installed version, available backup options may include:

  • Manual data backup.
  • Local backup files.
  • Scheduled backups.
  • Encrypted backups.
  • Data export.
  • Cloud backup integration.

Availability of these features should be confirmed within the installed application.

6.2 Recovery Information

Users should securely maintain any passwords, recovery keys or other information required to restore protected backups.

Recovery information should not be shared through public messages, screenshots or support requests.

6.3 Backup Verification

  • Confirm that backup files have been created successfully.
  • Verify that backup files are readable.
  • Check application version compatibility.
  • Maintain additional copies in secure locations.
  • Preserve original backup files before attempting recovery.
  • Where supported, verify recovery using a safe test environment.
Recovery Warning

Do not delete existing financial records or overwrite important backups until you have confirmed that your information can be restored.

Recovery may not be possible if required encryption keys, passwords or valid backup files are unavailable.

13. User Responsibilities

Users play an important role in protecting their personal, business and financial information.

Device Protection

  • Use a secure device screen lock.
  • Install trusted operating system updates.
  • Avoid untrusted applications.
  • Restrict unauthorized device access.
🔑

Password Protection

  • Use strong and unique passwords.
  • Protect application PINs.
  • Never share OTPs.
  • Keep recovery keys confidential.
💾

Backup Protection

  • Maintain regular verified backups.
  • Store backups securely.
  • Protect backup passwords.
  • Verify recovery before deleting data.
📥

Safe Downloads

  • Use official download sources.
  • Review release information.
  • Avoid modified APK files.
  • Keep device security safeguards enabled.
💰

Financial Record Protection

  • Review financial records regularly.
  • Avoid unnecessary sensitive information.
  • Protect exported financial reports.
  • Share records only with authorized persons.
👥

Customer Privacy
