7. PWA and Offline Storage

The MeraHisab website includes Progressive Web App functionality. Its service worker is designed to cache selected public pages, stylesheets, scripts and icons.

  • Offline access depends on successful caching.
  • APK downloads are excluded from the intended PWA cache.
  • Contact and download.html pages are excluded from the intended page cache.
  • Website cache storage is separate from native Android application storage.
  • Clearing website cache may remove offline resources.

Actual cache behavior should be verified through service worker and browser testing. Available storage controls can be accessed through the PWA panel.

8. Data Security

Appropriate technical and user security safeguards are important for financial information.

  • HTTPS connections for website access.
  • Secure device authentication.
  • Appropriate access controls.
  • Encryption where suitable.
  • Secure backup storage.
  • Application integrity verification.
  • Regular software updates.
  • Security vulnerability testing.

These are recommended safeguards, not certification that every safeguard has been implemented.

No software or storage system can guarantee absolute security.

9. Backups and Data Recovery

Maintain independent backups of important financial records using available application features.

  • Keep backups in a secure location.
  • Protect backup passwords and recovery keys.
  • Verify that backups can be restored.
  • Avoid sharing unencrypted financial backups.
  • Create a backup before application updates.
  • Do not assume uninstalling an application preserves its data.

Backup formats, encryption, automated backup schedules and recovery capabilities must be verified separately for each application.

Privacy Frequently Asked Questions

Are my financial records uploaded to a server?

The website calculator engine processes inputs locally. Native application data flows require separate verification.

Does the website save calculator inputs?

The calculator engine does not intentionally persist entered amounts or calculation results. Browser behavior may vary according to browser settings.

Does the website use cookies?

Website preferences may use browser storage. Hosting or external services may have their own storage practices. A complete cookie audit is pending.

Are application records encrypted?

Encryption implementation must be verified separately for each released application before making this claim.

Can I clear website storage?

Yes. Use browser site settings or available PWA controls. Clearing website cache may remove offline functionality until resources are downloaded again.

Will clearing website cache delete Android application records?

Website cache and native Android application storage are separate. Do not clear native application storage without securing a backup.

Can I request deletion of personal data?

Applicable privacy rights may include requesting erasure. Official contact and request handling procedures require configuration.

Does APK checksum verification guarantee safety?

No. A checksum comparison establishes file integrity against a trusted reference. It does not independently establish malware safety or developer authenticity.

Can I use the website offline?

Selected public website resources may be available offline after successful PWA caching.

How can I report a privacy issue?

Visit the Contact & Support page for available reporting information. Do not include unnecessary sensitive financial information.
